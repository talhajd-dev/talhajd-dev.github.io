# Talha — Personal Portfolio

A responsive student portfolio built with HTML, CSS and JavaScript.

## Before publishing
- Replace the three project placeholders with real course labs/projects.
- Edit the skills section to include only skills you can demonstrate.
- Confirm the biography is accurate.
- Replace the LinkedIn and professional email placeholders.
- Do not publish a phone number or home address.

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Publish with GitHub Pages
1. Push these files to the public repository `talhajd-dev.github.io`.
2. In the repository, open **Settings → Pages**.
3. Under Build and deployment, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then save.
5. Wait for deployment and visit https://talhajd-dev.github.io.
